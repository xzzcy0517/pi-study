## 这个教程怎么用

1. **按顺序读**：第 1 讲 → 第 7 讲，每讲只处理脚本的一小段；
2. **动手跑**：每讲的「🧪 动手跑」里是一整块命令，**整段复制**粘贴到终端（macOS 的「终端」App），回车；
3. **对输出**：终端打印的内容应该和教程里的「预期输出」基本一致。不一样就停下来，把报错发给我；
4. **不用背**：看懂、跑通即可。忘了随时回来翻。

预计总时长：跟着跑完约 40–60 分钟。

## 这个文件是干什么的？（30 秒版）

`pi-test.sh` 是 **Pi 的启动器**。

打个比方：Pi 是一台机器，`pi-test.sh` 就是机器的**开机按钮**。你按一下（运行它），它做三件小事：找到自己的位置 → 检查你给它的参数 → 把机器（node 程序）点火启动。然后它就退到一边，屏幕上出现的是 Pi 本体的交互界面。

它本身不实现 Pi 的任何功能——**它的全部工作，就是「正确地启动 Pi」**。

## 读之前，准备两样东西

- 一个终端窗口（macOS：启动台 → 其他 → 终端）；
- 确认 Pi 的代码在：`ls /Users/admin/Desktop/pi-study/pi` 能看到一堆文件即可。

> 动手实验的文件都放在 `c-pi/labs/`（你的学习目录里，教程命令会自动建好）。整个 `labs` 可以随时删掉，不影响任何正式文件。
